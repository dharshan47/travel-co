# 🌍 Travel Co

A premium, modern, and responsive **React + TypeScript** travel platform built with **Vite** and **Tailwind CSS 4**.  
Travel Co provides a seamless experience for exploring exotic destinations, uncovering top-tier travel services, and planning your next adventure with an elegant, interactive interface.

> [!NOTE]
> This project is optimized for performance using Vite's lightning-fast bundling and Tailwind CSS 4's modern styling capabilities.

## ✨ Features

- **🏞️ Destination Discovery**: Explore curated travel spots with high-quality visual previews.
- **🛠️ Integrated Services**: Overview of professional travel planning and support services.
- **🤝 Client Showcase**: Dedicated section highlighting our trusted partners and clients.
- **📱 Responsive Design**: Perfectly tailored for mobile, tablet, and desktop viewing.
- **⚡ Ultra-fast Performance**: Built on Vite for near-instant load times and HMR.
- **🎨 Modern Aesthetic**: Clean UI with smooth transitions and premium typography.

## 🛠️ Installation & Setup

Follow these steps to get the project running locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/dharshan47/travel-co.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd "Travel Co"
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

---

## 📜 Available Scripts

- `npm run dev` - Starts the Vite development server.
- `npm run build` - Builds the project for production.
- `npm run lint` - Runs ESLint to check for code quality issues.
- `npm run preview` - Locally previews the production build.
